# Ogment.ai Website Rebrand Brief

## Company
Ogment.ai — Enterprise Platform for MCP (Model Context Protocol)

## Current Site
https://www.ogment.ai — current design is clean but generic enterprise SaaS. Needs a COMPLETE brand overhaul.

## Value Prop
"Building a prototype MCP takes minutes. Getting it production-ready takes months. Ogment closes that gap."

## Core Product Pillars
1. **Build** — Technical PMs describe MCPs in plain English. AI generates production-grade servers. Engineers review and approve.
2. **Marketplace** — 300+ enterprise-ready connectors with auth and governance built in.
3. **Govern** — Auth, permissions, audit logs, VPC options. Born compliant.
4. **Monitor & Improve** — Track sessions, tool calls, user intent.

## Use Cases
- Internal Productivity (query Salesforce + Jira + Notion from one AI conversation)
- Customer-Facing Products (your product shows up inside ChatGPT/Claude)
- Agentic Workflows (multi-step agent pipelines with audit trails)
- Partner Distribution (scoped API access through AI assistants)

## FAQ Content (keep these)
- Ogment vs governance-only tools
- Ogment vs developer frameworks
- Do I need developers?
- How long to go from demo to production?
- Security & compliance options
- What is MCP?

## Design Direction
- COMPLETELY different brand from current
- Bold, modern, developer-friendly but enterprise-credible
- Think: Linear, Vercel, Resend — dark mode, sharp typography, confident
- Not generic enterprise blue/gray
- Make it feel like the future of infrastructure, not another SaaS landing page
- Subtle animations, gradient accents, clean sections
- Mobile responsive
- Single page with smooth scroll sections

## Tech
- Single HTML file with embedded CSS and minimal JS
- No frameworks needed — pure HTML/CSS/JS
- Use Inter or similar modern font (Google Fonts)
- SVG icons (inline or Lucide)
